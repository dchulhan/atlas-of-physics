# Glossary

- Chapter: one of the fifteen physics subjects; identified by its directory slug.
- Page: a zero-based hash position rendered as a numbered book page.
- World: a Three.js scene built from a physics model.
- Plate: an expanded explanation opened by picking a part of a figure.
- Practice: page-specific multiple-choice or worked-answer questions.
- Static Assets: Cloudflare's hosting of the built HTML, CSS, JavaScript and images.
